# DSA Java

Java practice from the Apna College DSA track. Each folder is one topic: a main walkthrough class, then practice questions (`PQ` / `PA`) and extra drills (`AQ`).

Not a library. Open a `.java` file, compile it, run it.

```text
javac Arrays/Array.java
java -cp Arrays Array
```

Some filenames contain spaces (`Variables & Data Types`). Quote the path.

## Topics

| Folder | What is in it |
| --- | --- |
| `Variables & Data Types` | types, input, first practice |
| `Operators` | arithmetic / bitwise / assignment recap |
| `Conditionals` | if / else / switch |
| `Loops` | for / while / nested |
| `Patterns` | star and number patterns, including the advanced set |
| `Function` | methods, overloading |
| `Arrays` / `Arrays_II` | 1D arrays, then the harder follow-up set |
| `2D-Arrays` | matrices |
| `Strings` | String / StringBuilder drills |
| `BitManipulation` | masks, get/set/clear bit |
| `BasicSorting` | bubble, selection, insertion |
| `OOPS` | classes, constructors, inheritance notes |

Needs a JDK 8+ on PATH. No build tool, no tests, no package declarations.
